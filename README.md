## About

This is my personal portfolio website, built using modern web technologies to showcase my projects, skills, experience, education, and other professional information.

The portfolio is based on **Next.js** and uses **TypeScript, Tailwind CSS, Shadcn/UI, Framer Motion, and Magic UI** for its design and functionality.

## ✨ Features

* Responsive design for desktop, tablet, and mobile devices
* Personal introduction and profile
* Education and experience
* Skills and technologies
* Projects showcase
* Blog section
* Contact information
* Modern UI and animations
* Optimized for Next.js
* Deployed online for public access

## 🚀 Getting Started Locally

### 1. Clone the repository

```bash
git clone https://github.com/aliyazafar07/My-portfolio.git
```

### 2. Move into the project directory

```bash
cd My-portfolio
```

### 3. Install dependencies

Using pnpm:

```bash
pnpm install
```

Or using npm:

```bash
npm install
```
  

### 4. Start the development server

Using pnpm:git

```bash
pnpm dev
```

Or using npm:

```bash
npm run dev
```

### 5. Open the portfolio

Open the development server in your browser:

```text
http://localhost:3000
```

## ⚙️ Customization

Most of the personal portfolio information can be customized from:

```text

```

You can update information such as:

* Personal information
* Education
* Work experience
* Skills
* Projects
* Social links
* Contact information
